# vexxplugins.github.io

Home of Vexx Audio, at <https://vexxplugins.github.io>. Static HTML and CSS, no build step and no
external requests: fonts and logo are served from this repository. Two small inline scripts handle
the light/dark toggle, and the dark theme also works with JavaScript disabled.

The home page is a hub: the story of the label and one card per plugin. Each product has its own
page, published from its own repository, so the copy stays next to the code it describes:

- Retroexx: <https://vexxplugins.github.io/retroexx/>, from `docs/` in
  [VexxPlugins/retroexx](https://github.com/VexxPlugins/retroexx).

## Files

- `index.html` is the whole home page.
- `assets/style.css` holds the tokens and layout. The palette and type come from the design
  contract in the Retroexx repository (`DESIGN.md`, sections 1 and 2); the stylesheet is shared
  with that product page and the two copies are kept identical.
- `assets/fonts/` carries Orbitron and Rajdhani under the SIL Open Font License.
- `assets/retroexx-preview.jpg` is a downscaled frame of the editor, generated by the plugin test
  suite and published full size in the product page.

Published with GitHub Pages from the root of `main`.
